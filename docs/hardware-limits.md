# Mega Drive / Mega CD hardware limits (both machines share the same VDP)

## Confirmed: the Mega CD does NOT relax any video limit
The Sega CD (Mega CD) adds a CD drive, 256 KB Word RAM, a second 68000 and PCM
audio. **Video is still generated by the Genesis VDP (Yamaha FD1094 + 315-5313)**,
so every Genesis display limit below applies unchanged to a Mega CD title.

## Colour
- CRAM = 64 words of 9-bit colours = **64 colours on screen, period**
  (4 palettes x 16 colours, shared between background planes and sprites).
- PC Engine by comparison has 16 BG palettes + 16 sprite palettes = 512
  simultaneous colours, and **16 colours per sprite**.
- A Genesis sprite is limited to 16 colours = **one palette line per sprite**,
  and only 4 palette lines exist for everything.

## Sprites (the "64" limit is the H32 mode)
Sega's own software manual states the limit depends on screen width:

| Mode  | Screen    | Sprites/frame | Sprites/scanline | Sprite dots/scanline |
|-------|-----------|---------------|------------------|----------------------|
| H40   | 320x224   | **80**        | **20**           | **320** (40 tiles)   |
| H32   | 256x224   | **64**        | **16**           | **256** (32 tiles)   |

- Excess sprites are silently dropped on that scanline (highest link value wins).
- A sprite of N cells wide must start at a tile index multiple of N.
- Max sprite size 4x4 cells = 32x32 pixels (composite sprites cost one SAT
  entry each).
- Sprite `X = 0` masks all lower-priority sprites on that scanline.
- PC Engine by comparison: 64 sprites, 16x16..16x64, also limited per line.

**Conclusion for this port:** we will run in H40 (320x224) like every Mega CD
title, so the budget is 80 sprites / 20 per line. We still keep our object count
per scanline low, because 4-cell-wide sprites burn the 40-tile budget fast.
- Sprite patterns are 8x8 cells, 4bpp, and must be tile-aligned: a sprite of
  N cells wide must start at a tile index that is a multiple of N.
- Max sprite size 4x4 cells = 32x32 pixels (composite sprites cost one SAT
  entry each).
- PC Engine by comparison: 64 sprites, 16x16..16x64, also limited per line.

## Planes
- Plane A (32x28..64x32 cells), Plane B (64x32 cells max), Window plane.
- Plane A and Plane B can scroll horizontally *and* vertically on Genesis
  (no per-plane restriction like the Master System).

## Consequence for this port
- **Palette budget is the hardest constraint**: PCE → 64 colours means heavy
  colour reduction, mid-frame CRAM swaps, and per-stage palettes.
- Sprite engine must use composite sprites and respect the 20/line limit
  (the same way the PCE respects its own).
